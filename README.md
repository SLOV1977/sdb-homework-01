### Задание 1. СУБД

7. `Департамент логистики нуждается в решении задач по быстрому формированию маршрутов доставки материалов по объектам и распределению курьеров по маршрутам с доставкой документов. СУБД должна уметь быстро работать со связями.`
8. `Можно ли к этой СУБД подключить отдел закупок или для них лучше сформировать свою СУБД в связке с СУБД логистов?`
9. `Можно ли все перечисленные выше задачи решить, используя одну СУБД? Если да, то какую именно?`

### Задание 2. Транзакции

1. `Пользователь пополняет баланс счёта телефона, распишите пошагово, какие действия должны произойти для того, чтобы транзакция завершилась успешно. Ориентируйтесь на шесть действий.`
2. `Какие действия должны произойти, если пополнение счёта телефона происходило бы через автоплатёж?`

### Решение 2

1. 
   1. `Начало транзакции. Соединение с базой данных платёжного счёта. Чтение баланса платёжного счёта. Ввод необходимой суммы для перевода на счёт телефона.`
   2. `Уменьшение баланса платёжного счёта на сумму, указанную пользователем.`
   3. `Сохранение баланса платёжного счёта.`
   4. `Соединение с базой данных счёта телефона и чтение баланса.`
   5. `Увеличение баланса счёта телефона на указанную сумму.`
   6. `Сохранение актуального баланса счёта телефона. При успешном выполнении всех пунктов происходит COMMIT всех изменений, при ошибке — ROLLBACK (откат всех действий).`

### Задание 3. SQL vs NoSQL

1. `Напишите пять преимуществ SQL-систем по отношению к NoSQL.`
2. `Какие, на ваш взгляд, преимущества у NewSQL систем перед SQL и NoSQL.`

### Решение 3

1. 
   1. `Гарантированная целостность и безопасность данных благодаря строгой типизации и ACID-транзакциям`
   2. `Стандартизированный язык запросов, облегчающий разработку и поддержку. Позволяет выполнять сложные операции с данными с помощью одного запроса.`
   3. `Развитая система управления правами доступа позволяет гибко управлять уровнем доступа к различным частям базы данных.`
   4. `Полная поддержка реляционных связей между таблицами обеспечивает возможность создания сложных структур данных и автоматического поддержания их целостности.`
   5. `Большое количество инструментов и готовых решений.`
2. `NewSQL сочетает в себе лучшие стороны SQL и NoSQL, такие как: SQL-запросы, ACID-транзакции, гибкость, горизонтальную масштабируемость, высокую производительность, возможность обработки больших объёмов данных, высокую отказоустойчивость.`

### Задание 4. Кластеры

`Необходимо производить большое количество вычислений при работе с огромным количеством данных, под эту задачу выделено 1000 машин. На основе какого критерия будете выбирать тип СУБД и какая модель распределённых вычислений здесь справится лучше всего и почему?`

### Решение 4

`При выборе СУБД для работы с большим количеством данных и вычислений необходимо учитывать тип данных, их структуру (структурированные или неструктурированные), объём, необходимую скорость обработки, требования к согласованности данных, масштабируемость системы, производительность при параллельных вычислениях`
`Поэтому для выполнения поставленной задачи лучше всего подойдёт NoSQL (например, Apache Cassandra) или NewSQL (например, CockroachDB), с моделью распределённых вычислений MapReduce (например, Apache Hadoop) или Spark.`
`NoSQL/NewSQL обеспечат горизонтальное масштабирование на 1000 машин, высокую доступность и обработку больших данных. Spark предпочтительнее MapReduce за счёт обработки в памяти, что ускоряет вычисления для аналитики и больших данных.`
